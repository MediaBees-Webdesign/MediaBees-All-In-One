# MB All-In-One

Modulares WordPress-Plugin von [MediaBees](https://mediabees.de/) für Kundenwebsites mit Elementor, Elementor Pro und Hello Elementor.

## Installation und Updates

1. Unter **Releases** die angehängte Datei `mediabees-all-in-one-X.Y.Z.zip` herunterladen (nicht „Source code“).
2. In WordPress unter **Plugins → Neues Plugin hinzufügen → Plugin hochladen** installieren und aktivieren.
3. Ab Version 1.41.0 kommen Updates automatisch aus den Releases dieses Repositorys.

Voraussetzungen: WordPress 7.0+, PHP 8.2+ mit `mbstring`.

Alle Funktionen erklärt die eingebaute Anleitung unter **Einstellungen → MB All-In-One → Anleitung**.
